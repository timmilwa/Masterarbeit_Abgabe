System Permissions

Kaleido requires certain system permissions to function properly. Click the buttons below to open System Settings where you can grant the necessary permissions.

Screen Recording

Required for capturing screenshots and screen content. This permission is needed for the capture artefact feature.

Accessibility

Required for monitoring keyboard shortcuts (like ⌘⌘ for capture artefact and ⌥⌘ for open canvas). This permission enables global keyboard event detection.

Open All Permissions

Opens System Settings to Privacy & Security where you can manage all permissions at once.
